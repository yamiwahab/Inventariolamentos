Manifiesto Fundacional

Por qué necesitamos una arquitectura para lo que callamos

Vivimos en ciudades y pantallas diseñadas exclusivamente para el ruido, la prisa y la exposición. Todo nos empuja a producir, a explicar lo que sentimos o a fingir que estamos enteros cuando el mundo pesa demasiado. Pero no existe ningún refugio para lo que decidimos callar.

"La suma de millones de soledades individuales no es un abismo: es una constelación compartida."

El Gran Inventario de los Duelos Anónimos no es una red social ni un archivo de nombres. Es un santuario digital y una escultura viva de datos humanos. Aquí no pedimos palabras, ni formularios, ni explicaciones.

Los 3 Pilares Éticos del Santuario:

  • ✦ Anonimato Sagrado: Nadie sabe quién sos. Tu gesto se transforma únicamente en duración lumínica y coordenada horaria.
  • ✦ El Silencio como Lenguaje: Cuando hablar agota, el peso de mantener presionado un punto de luz dice todo lo que las palabras no alcanzan a nombrar.
  • ✦ Consuelo Colectivo: Ver titilar miles de silencios en Buenos Aires, Madrid, Tokio o Montevideo nos recuerda que la fragilidad no es una falla personal, sino el puente más humano que tenemos.

Guía Rápida de Lanzamiento

Cómo publicar este prototipo en GitHub Pages

¡Hola Agustín! Todo este proyecto (el motor 3D de Three.js, la síntesis sonora y la base de datos en tiempo real) está empaquetado en un único archivo index.html listo para subir.

Paso 1: Crear el Repositorio en GitHub

Entrá a github.com/new, ponele de nombre inventario-duelos-anonimos, dejalo en modo Public y hacé clic en Create repository.

Paso 2: Subir el archivo index.html

Dentro de tu nuevo repositorio, hacé clic en "uploading an existing file", arrastrá el archivo index.html que descargaste con el botón de arriba y tocá el botón verde Commit changes.

Paso 3: Activar la página web gratis (GitHub Pages)

Andá a la pestaña Settings del repositorio → en el menú izquierdo entrá a Pages → donde dice Branch cambiá "None" por main y tocá Save. ¡En 60 segundos te dará el link público oficial para compartir con quien quieran!
